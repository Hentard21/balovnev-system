# Balovnev Mini App

Telegram Mini App для клиентов Игоря Баловнева: клиент отправляет замеры
(вес, вода, самочувствие, фото, БАДы/анаболики) и видит свою историю;
тренер видит дашборд по каждому клиенту.

Стек: Next.js (App Router, обычный сервер — не статический экспорт) +
Prisma + SQLite. База физически хранится на диске сервера — это осознанный
выбор из-за требования локализации персональных данных граждан РФ (ст. 18
ч. 5 152-ФЗ): среди полей есть данные о здоровье (самочувствие, БАДы,
анаболики, фото тела), поэтому DB должна жить на VPS в России, не в
зарубежном облаке (Supabase/AWS и т.п.).

## Локальная разработка

```bash
npm install
cp .env.example .env
npm run prisma:migrate   # создаёт data/miniapp.db и таблицы (путь задаётся
                         # в .env как file:../data/miniapp.db — см. комментарий там)
npm run dev
```

Открой http://localhost:3000 в обычном браузере — сработает `DEV_AUTH_BYPASS`
из `.env` (мок-пользователь вместо реального Telegram). Для входа как
тренер впиши `TRAINER_TELEGRAM_ID` в `.env`, совпадающий с `id` мок-юзера
в `src/app/api/auth/route.ts` (по умолчанию `111111111`), либо просто
открой `/trainer` — роль переключится после того, как реальный бот будет
подключён.

**Важно:** `DEV_AUTH_BYPASS=true` не должен попасть в prod `.env` — код и
так игнорирует его при `NODE_ENV=production`, но держите переменную только
в локальном `.env`.

## Создание бота и подключение Mini App (когда будете готовы)

1. В Telegram напишите **@BotFather** → `/newbot`, задайте имя и username
   (например `balovnev_fitness_bot`). Получите **токен** — вставьте его в
   `TELEGRAM_BOT_TOKEN` на сервере.
2. `/mybots` → выберите бота → **Bot Settings → Menu Button → Configure
   menu button** (или **Mini App**) → укажите URL вашего задеплоенного
   приложения (обязательно `https://…`).
3. Узнайте свой Telegram id (напишите **@userinfobot**) и впишите его в
   `TRAINER_TELEGRAM_ID` — по этому id приложение автоматически откроет
   вам дашборд тренера вместо клиентского экрана.
4. Разошлите клиентам ссылку на бота — открывая его, они попадают в Mini
   App и сразу видят свой личный кабинет.

## Деплой на VPS (Россия)

Нужен VPS у российского провайдера (Timeweb Cloud, REG.ru, Beget,
Selectel и т.п.) и домен с HTTPS — Telegram Mini App должен открываться
только по `https://`. Проще всего поставить обратный прокси с
авто-TLS (например Caddy) перед контейнером на порту 3000.

```bash
git clone <репозиторий> && cd miniapp
cp .env.example .env        # заполните TELEGRAM_BOT_TOKEN, TRAINER_TELEGRAM_ID,
                             # SESSION_SECRET (длинная случайная строка),
                             # DEV_AUTH_BYPASS=false
docker compose up -d --build
```

`data/` и `uploads/` — volume-каталоги рядом с `docker-compose.yml`,
сохраняются между пересборками. Настройте их регулярный бэкап (это
единственная копия данных клиентов).

### Обновление

```bash
git pull
docker compose up -d --build   # миграции применяются автоматически при старте
```

## Структура данных

- `User` — клиент или тренер (роль определяется по `TRAINER_TELEGRAM_ID`).
- `Measurement` — один замер: вес, вода, самочувствие, БАДы, анаболики
  (JSON-массивы строк), комментарий, дата.
- `Photo` — фото замера, файл лежит в `uploads/<clientId>/<measurementId>/`,
  отдаётся только через авторизованный роут `/api/photos/[id]` (владельцу
  или тренеру), никогда напрямую и не индексируется.
